# Orbit

Orbit is an AI assistant designed to help with engineering and software projects (like an E.V. from Spider-Man :) ).

The goal is to create an assistant capable of understanding project documentation, source code, tests, logs, calculations, and technical decisions. Instead of working as a simple chatbot, Orbit will use real tools to inspect projects, execute safe actions, and provide answers based on the available context.

Each project will be able to define its own documentation, commands, tools, and permissions through a configuration file.

The first version will be a command-line application written in Rust. Voice interaction, MCP support, persistent memory, and a desktop application may be added as the project evolves.
